MÓDULO: GESTOR DE DADOS FINANCEIRO (BALANÇO GERENCIAL)
Objetivo

O Gestor de Dados Financeiro será o responsável por validar, auditar, reconciliar e certificar todos os números apresentados no Balanço Gerencial.

Este módulo será a camada de inteligência que garante que todos os indicadores financeiros exibidos no sistema sejam verdadeiros, consistentes e sincronizados com a base oficial de dados.

Nenhum KPI deverá ser exibido sem antes passar pela validação do Gestor de Dados Financeiro.

Localização

Implementar esta tela dentro do menu:

Diretoria → Balanço Gerencial → Gestor de Dados Financeiro

Esta será a principal tela de auditoria financeira da empresa.

Critérios de Aceite

O Gestor de Dados Financeiro somente será considerado concluído quando:

Auditar automaticamente todos os indicadores financeiros antes da exibição.
Detectar duplicidades, inconsistências e divergências.
Explicar a origem de cada erro encontrado.
Exibir a tela exatamente no padrão visual aprovado pela Diretoria.
Apresentar o detalhamento completo dos custos dos funcionários no painel de hover.
Utilizar o Knowledge Graph para validar todos os relacionamentos.
Manter sincronização em tempo real com todos os módulos do sistema.
Garantir que nenhum indicador seja exibido com dados inconsistentes ou desatualizados.

Essa abordagem transforma o Gestor de Dados Financeiro no "guardião da verdade" do seu ERP. Em vez de ser apenas um dashboard, ele passa a certificar a qualidade dos dados antes que eles alimentem o Balanço Gerencial, o Cockpit da Diretoria, o Gestor Comercial e os futuros gestores Operacional, Contábil e Financeiro. Isso cria uma base muito mais confiável para a tomada de decisão.
